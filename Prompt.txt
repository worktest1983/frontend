ERP 產品管理系統 UI/UX 改造

請依據我提供的 HTML、CSS、JavaScript 程式碼，將目前的「產品建檔 CRUD 練習」改造成具有專業企業形象的 ERP 產品管理系統。

一、設計需求
1.參考真實 ERP 後台管理系統的設計風格，呈現專業、簡潔、現代化的商業介面。
2.使用 Bootstrap 進行 RWD 響應式排版，並透過自訂 CSS 美化介面。
3.加入適當的側邊導覽列、頂部資訊列、功能標題及操作區塊，提升整體系統完整度。
4.統一配色、字體、按鈕、表單與卡片風格，強化視覺層次。
5.優化產品建檔、資料確認、送出結果等操作流程，讓使用體驗更加直覺流暢。
6.適度加入圖示、Hover 效果及簡單的 CSS 動畫，不過度設計。

二、程式限制
1.保留現有 JavaScript 與 jQuery 的主要邏輯，不進行大幅修改或重構。
2.保留原本的欄位 ID、事件監聽、flag 驗證、JSON 資料結構及 AJAX API 串接。
3.不使用 Vue、React 或其他前端框架。
4.以修改 HTML 結構、Bootstrap Class 及自訂 CSS 為主。
5.如因 UI 操作需求必須修改 JS，只允許最小幅度調整，並註明修改原因。
6.不加入尚未實作的 CRUD 功能，避免產生無法操作的假按鈕。

三、預期成果
1.整體介面具有真實 ERP 後台管理系統的質感。
2.保留原本產品新增與 JSON Server API 功能。
3.操作流程清楚，適合企業內部人員使用。
4.提供完整、可直接複製執行的 HTML、CSS、JavaScript 程式碼。
5.程式碼保持原本的撰寫風格，方便初學者閱讀及後續教學。
